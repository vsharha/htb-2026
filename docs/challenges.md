# MLH challenges

MLH awards these prizes for using specific technologies. They are separate from the sponsor tracks in `tracks.md`, and a project can win both. Source: the MLH email for HackTheBurgh, 6 November 2026.

Some technologies have promo codes, claimed through links in the MLH email. Do not store the codes in this repository.

## Gemini API

- Prize: MLH swag kits.
- What qualifies: the project is built on the Google Gemini API.
- Sign-up: API key from Google AI Studio. MLH runs an "Intro to Google AI Studio" workshop at the event.

## ElevenLabs

- Prize: wireless earbuds.
- What qualifies: the project generates voice or audio with ElevenLabs.
- Sign-up: promo code available (Q4 2025 – Q4 2026).

## Entire

- Prize: mini portable projector.
- What qualifies: the team's development workflow uses as many of Entire's capabilities as possible:
  - Sessions: agent sessions saved as checkpoints and pushed so teammates or other agents can resume them.
  - Graph: a map of the codebase that agents search instead of searching files.
  - Brain: project knowledge built from sessions and Graph, queryable through the CLI or MCP.
  - Trails: Entire's combined issue and pull request, where an agent does a task and another agent reviews it.
- Judges look for human-agent collaboration, clean code history, and measurable token efficiency.
- Sign-up: promo code available (Q4 2026 – Q3 2027).
- This challenge judges how we build, not what we build. If we target it, its setup goes in `AGENTS.md`.

## Solana

- Prize: unruggable hardware wallets for each team member.
- What qualifies: the project is built on Solana.

## Tiger Data

- Prize: Stream Deck Mini.
- What qualifies: the project uses Tiger Data, a PostgreSQL extension for real-time, time-series and analytics data. Judges look for an innovative, impactful and performance-driven use.

## Vultr

- Prize: assorted prizes.
- What qualifies: the project runs on Vultr (cloud compute or cloud GPUs).
- Sign-up: free cloud credits on account creation.

## Auth0

- Prize: wireless headphones for each team member.
- What qualifies: the project uses any Auth0 API.
- Sign-up: free, no credit card required.
