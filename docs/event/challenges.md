# MLH challenges

MLH awards these prizes for using specific technologies. They are separate from the sponsor tracks in `tracks.md`, and a project can win both.

- Source: the MLH email for HackTheBurgh, 6 November 2026, stored as `reference/mlh/mlh-email-2026-11-06.pdf`.
- Source: MLH prize descriptions provided in chat on 7 November 2026, stored as `reference/mlh/mlh-prizes-2026-11-07.md`.

Some technologies have promo codes, claimed through links in the MLH material. Do not store the codes in this repository.

## Gemini API

- Prize: MLH swag kits.
- What qualifies: the project is built on the Google Gemini API.
- What it can do (examples given): understand language and power a chatbot that gives personalized advice; analyze information and summarize complex research papers; generate creative content such as code, scripts and music.
- Sign-up: API key from Google AI Studio. MLH runs an "Intro to Google AI Studio" workshop at the event.

## ElevenLabs

- Prize: wireless earbuds.
- What qualifies: the project generates voice or audio with ElevenLabs, integrating fully autonomous audio experiences. ElevenLabs generates realistic, dynamic and emotionally expressive voices for projects such as interactive AI companions, narrated stories and voice-enabled apps, without actors or complex audio production.
- Sign-up: promo code available (Q4 2025 – Q4 2026).

## Entire

- Prize: mini portable projector.
- Brief: Entire is a Git forge for agent-human collaboration (syncing sessions and prompts to Git history, hosting code, and replacing pull requests with Trails). Build smarter AI workflows that use as many of Entire's core capabilities (Sessions, Graph and/or Brain) as possible, leaning on Sessions for context/memory and `entire graph` search for codebase mapping.
- What qualifies (core capabilities):
  - Sessions (shared memory): save AI agent sessions as checkpoints and push them so teammates or other agents can resume with no context loss.
  - Graph (codebase mapping): generate a visual map of how the codebase fits together. Using `entire graph` search instead of letting agents search files blindly can cut token usage by up to 71%.
  - Brain (persistent reasoning): combine session data and Graph insights into persistent project knowledge, queryable through the CLI or MCP so agents do not repeat mistakes or undo working code.
  - Trails (code review): assign an agent a task via a Trail (Entire's issue/pull-request primitive), let the agent work on it, then have an agent review whether the change matches the intent and should merge.
- Judges look for seamless human-AI collaboration, clean code history, and measurable token efficiency.
- Sign-up: promo code available (Q4 2026 – Q3 2027).
- This challenge judges how we build, not what we build. If we target it, its setup goes in `AGENTS.md`.

## Solana

- Prize: unruggable hardware wallets for each team member.
- What qualifies: the project is built on Solana, using advantages such as fast execution and near-zero transaction costs.
- Project ideas given: a game, social app or consumer product relying on instant, high-frequency transactions; a trading, lending or decentralized exchange product; or a prototype for supply chain, identity or payments that can handle large real-world volume.

## Tiger Data

- Prize: Stream Deck Mini.
- What qualifies: the project uses Tiger Data, a PostgreSQL extension for real-time, time-series and analytics data. Judges look for an innovative, impactful and performance-driven use.
- Features highlighted: standard SQL (no complex NoSQL aggregation pipelines); relational user profiles and high-frequency metric streams in one database; instant dashboards with pre-computed Continuous Aggregates; 90%+ data compression to store millions of events on free-tier cloud instances.
- Example uses given: real-time IoT monitoring, AI-driven analytics dashboards, financial prediction engines.

- Sign-up: free cloud credits on account creation.

## Auth0

- Prize: wireless headphones for each team member.
- What qualifies: the project uses any Auth0 API. Auth0 provides features such as social sign-in, multi-factor authentication and passwordless log-in, and can secure AI applications with Auth0 for AI Agents.
- Sign-up: free to try, no credit card required, up to 7,000 free active users and unlimited log-ins.
