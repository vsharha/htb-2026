# Project submission form

These are the questions on the HackTheBurgh project submission form. Write each answer under its question. Submissions close on 8 November 2026 at 12:00 GMT, and the form can be edited until then. An asterisk marks a required question.

## Q1. Project title

_Give your project a title for the live display (including public project page). Leave blank to use your team name._

## Q2. Tagline

_Describe your project in one sentence, up to 140 characters._

## Q3. Tracks \*

_Select all tracks you would like to enter with your project. You can choose multiple tracks, but can only submit a single project as a team._

_Show your project with screenshots; these do not need to be slides. Add up to 8 PNG, JPEG or WebP images, up to 5 MB each. The first image is the cover on the live display (including public project page)._

_Add up to four usernames, including your own. One person can list everyone on the team. Use Discord usernames, not display names._
